❤️ Heart Disease Prediction System

A Streamlit-based Machine Learning web application that predicts heart disease risk using clinical data. It supports single and bulk predictions, 
compares multiple ML models, and provides real-time results with ~89% accuracy using an optimized Random Forest model.

🚀 Features

Single and bulk (CSV) heart disease prediction
Multiple ML model comparison
Interactive Streamlit web interface
Downloadable prediction reports

🛠 Tech Stack
Python, Streamlit
Scikit-learn, Pandas, NumPy
Models: Logistic Regression, Decision Tree, Random Forest, SVM

▶️ Run Locally
pip install -r requirements.txt
streamlit run app.py
